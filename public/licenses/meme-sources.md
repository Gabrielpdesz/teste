# Fontes das imagens de reação

Templates encontrados na coleção pública [memegen](https://github.com/jacebrowning/memegen/tree/main/templates). Os links abaixo registram as fontes das imagens; não atribuem ao projeto a autoria dos personagens ou fotografias. O catálogo utiliza cópias locais otimizadas, sem depender da API externa.

| Presente | Template | Fonte consultada |
| --- | --- | --- |
| Um dia de sol na lua de mel | Success Kid, meme originado de uma foto na praia | [success](https://github.com/jacebrowning/memegen/tree/main/templates/success) |
| Uma aventura na lua de mel | Woody e Buzz, Toy Story | [buzz](https://github.com/jacebrowning/memegen/tree/main/templates/buzz) |
| Uma noite nas nuvens | Tuxedo Winnie the Pooh, reação de sofisticação | [pooh](https://github.com/jacebrowning/memegen/tree/main/templates/pooh) |
| As malas para a nossa aventura | Two Guys on a Bus, viagem | [bus](https://github.com/jacebrowning/memegen/tree/main/templates/bus) |
| Um café antes do nosso sim | Caco com uma bebida | [kermit](https://github.com/jacebrowning/memegen/tree/main/templates/kermit) |
| Nosso primeiro jantar de casados | Salt Bae, cena de preparo de comida | [saltbae](https://github.com/jacebrowning/memegen/tree/main/templates/saltbae) |
| Uma pausa só para nós dois | Feels Good, reação de relaxamento | [feelsgood](https://github.com/jacebrowning/memegen/tree/main/templates/feelsgood) |
| Adoçar a nossa nova vida | Willy Wonka, referência à fábrica de chocolate | [wonka](https://github.com/jacebrowning/memegen/tree/main/templates/wonka) |

As imagens foram redimensionadas e codificadas em WebP para reduzir o tamanho do site. O template do Pooh mantém os dois quadros, com a área vazia para legendas recortada apenas na apresentação do cartão.
